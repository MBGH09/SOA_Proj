6. S4-04 – VerifierEtReserver (local path)
----------------------------------------------------------------
File: grpc/DonStockGrpcService.java

Flow:
  1. Validate quantity >= 1, groupe, composant, urgence → INVALID_ARGUMENT
  2. Check lieu exists                                  → NOT_FOUND
  3. Idempotency: if demande_id already exists, return stored answer
  4. If lieu.stock_local = true:
       Lock stock row (SELECT FOR UPDATE / PESSIMISTIC_WRITE)
       If disponible >= quantite:
         disponible -= quantite, reserve += quantite
         Save reservation as RESERVEE_STOCK_LOCAL
         Publish StockChangeEvent → stream subscribers notified
  5. If local stock insufficient → central path (S4-05)

9. S4-07 – EnregistrerPrelevement
----------------------------------------------------------------
File: grpc/DonStockGrpcService.java

Flow:
  1. Validate volume_ml == 450, groupe_sanguin set → INVALID_ARGUMENT
  2. Idempotency by don_id:
       If exists and A_DECLARER → retry SOAP call
       If exists and other status → return stored answer
  3. Insert row as A_DECLARER
  4. Call SOAP enregistrerPrelevement (stubbed until S4-12)
       On success: numero_don_national saved, status → QUALIFICATION_EN_COURS
                   en_qualification += 1 for each component at the centre

12. S4-10 – SuivreNiveauxStock (server streaming)
----------------------------------------------------------------
Files:
  grpc/StockStreamRegistry.java
  grpc/StockChangeEventListener.java
  grpc/StockNiveauMapper.java
  event/StockChangeEvent.java

How it works:
  1. Client calls SuivreNiveauxStock with optional filters (lieu_id, groupe_sanguin)
  2. Subscriber registered in StockStreamRegistry (ConcurrentHashMap, thread-safe)
  3. Current snapshot sent immediately (all matching stock_niveau rows)
  4. Cancel handler: when client disconnects, subscriber is auto-removed
  5. After every DB commit that changes stock, StockChangeEvent is published
  6. StockChangeEventListener fires @TransactionalEventListener(AFTER_COMMIT)
     so only committed data is pushed to clients
  7. Each changed row is mapped via StockNiveauMapper to NiveauStockMessage
  8. Niveau computed from seuil_alerte:
       BAS   = disponible <= seuil_alerte
       MOYEN = disponible <= 2 * seuil_alerte
       HAUT  = disponible >  2 * seuil_alerte

13. S4-11 – gRPC exception advice
----------------------------------------------------------------
File: grpc/GrpcExceptionAdvice.java

Centralised @GrpcAdvice class maps:
  IllegalArgumentException      → INVALID_ARGUMENT
  EntityNotFoundException       → NOT_FOUND
  IllegalStateException         → FAILED_PRECONDITION
  ConnectException              → UNAVAILABLE
  TimeoutException              → DEADLINE_EXCEEDED
  Any other Exception           → INTERNAL (no stack trace exposed)
